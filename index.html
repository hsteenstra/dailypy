How it works

1

A new puzzle daily

A fresh challenge unlocks every day at midnight. Difficulty rotates Easy, Medium, Hard, so there's always something you can do.

2

Write and run

Type Python in the editor and press Run to see what it prints. Everything runs in your browser, so there's nothing to install.

3

Check it

Check my code tests your answer. Pass every test to earn points, grow your streak, and unlock the solution.

Teachers and club leaders

Put today's challenge on the board as a warm-up, or have students keep a streak going. It works on school Chromebooks, and students don't need to sign up. New to Python? The free Code For ME Workbook covers everything these challenges use.
